Rules of the map

  • A prompt with no proof column is a bug in this table, not an exception.
  • The validator (runner/validate/) is code, not a prompt. Prompts may not be loosened to satisfy it, and it may not be loosened to satisfy a prompt.
  • When eve changes its layout, update the Runner table and the pinned commit in the header in one commit.
