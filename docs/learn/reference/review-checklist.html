Twenty-minute packet review

Run top to bottom. Stop the moment a box cannot be ticked; that is the finding.

from lesson 0001source: Google reviewer guide

Report (3 min)

  • A run report exists and names the packet.
  • Every "skipped", "could not", or "assumed" line is copied into my notes.
  • The report's claimed test result is treated as a claim, not a fact.

Diff to packet (4 min)

  • Each acceptance criterion maps to a file or test in the diff.
  • No change exists that no criterion asked for (or it is listed for split/revert).
  • No "while I was here" refactor touches files outside the packet's paths.

Proofs (5 min)

  • Smoke test run by me, output seen by me.
  • Packet fixtures run by me, including the hostile-content fixture when relevant.
  • No test marked skip/only; no fixture edited to make an assertion pass.

Risk surfaces (5 min)

  • Prompts: any changed prompt file has a fixture that proves the change.
  • Schemas and validators: nothing became optional, permissive, or "any".
  • Extension: manifest permissions and host permissions unchanged, or the change is justified against the browser-boundary research.
  • Workspace data: nothing writes personal context anywhere except the local workspace.

Decision (3 min)

  • Decision written into the packet file: merge / push back (numbered) / revert and re-run.
  • One line: what to change in the packet's prompt next time.

Agent-specific defects, in order of frequency: scope creep, weakened validators, untested prompt edits, new permissions, silent assumptions in the report.
