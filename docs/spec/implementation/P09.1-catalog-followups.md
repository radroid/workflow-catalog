## Goal
Make the install guide match the runner that P02 actually ships, and close the low follow-ups the P09-B reviewers left. P09 is done and no later packet owns the catalog, so these land here.

## Deliverables
- **Install commands match `runner/README.md`.** The guide in `apps/catalog/lib/install-commands.ts` still says `npx degit …/runner` and `npm install`, and to select `workflow-catalog/extension`. The runner now installs only from a whole-repo clone: its `workspace:*` dependencies need the pnpm workspace. The steps are:
  1. `git clone`
  2. `corepack enable`
  3. `pnpm install --frozen-lockfile`
  4. `cd runner`
  5. `npm run setup`
  6. `npm run doctor`
  7. `npm run runner`

  The extension loads unpacked from `extension/dist` after `pnpm --filter @workflow-catalog/extension build`. Copy the exact commands and prerequisites from `runner/README.md` and `extension/README.md`, including what ChatGPT mode needs from the Codex CLI. Drop the `degit` path.
- **A drift test.** Add a catalog test that reads the install code block in `runner/README.md` and fails when `INSTALL_STEPS` disagrees with it. It reads other paths only in the test and edits none of them. The checklist item IDs and labels must keep matching `npm run doctor` (`node`, `runner`, `provider`, `workspace`, `extension`).
- **Refusal nonce is tested.** Both refusal actions redirect with a fresh `n` nonce, but removing it leaves every test green. Add action-level tests: two identical refusals redirect with different `n` values.
- **The release lookup stops reading at the cap.** When the 4 KB checksum cap trips, cancel the body reader (`reader.cancel()`) or abort the fetch. The stalled-body tests also assert the "Request timed out." message.
- **UI notes from the critic:**
  - Even out the Download card spacing (`.card .lede` currently overrides `.tight`: 33px below against 19px above).
  - Bring the permission names down to below the card heading's visual weight.
  - Remove the identical "Required"/"Supported" pills, or make them carry information.
- **Changelog note.** Replace "the eve adapter (adapters/eve/) is a stub — P02 fills it in" in `workflow.json`'s 0.1.0 changelog with one plain sentence about what the eve adapter ships. It is not yet released, so the entry can still change.
