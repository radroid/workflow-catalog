# Fixtures policy

All fixture data in the repo is fictional. Allowed fictional companies: Northwind Labs, Fernwood, Harbor, Quill, Ledgerkit (a project). Allowed fictional people: Ada Quill, Sam Fernwood, Ravi Harbor. Allowed fictional URLs: `https://jobs.example/...`, `https://portfolio.example/...`. Never paste a real posting, resume, or profile. The hostile posting fixture must contain, verbatim, the phrase `ignore previous instructions` and a fake action request, so that tests can grep for them. `pnpm check:fixtures` enforces the email and URL rules on every tracked file; a test that needs a disallowed string (a real-domain email or URL) to prove a check fails must assemble it at runtime, because a literal trips the scanner.
