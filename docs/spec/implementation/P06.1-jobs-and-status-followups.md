## Deliverables
1. **The Jobs page** (P04's round-3 critic).
   1. If a job's only file becomes unreadable while focus is on its Re-extract button, the old "What the runner found" section stays under the new message, even after focus leaves. Move focus to the heading, then drop the section.
   2. When two extractions the page started finish in the same refresh, the first message is replaced before it's shown. Announce them in one message.
   3. The 80-character name cap cuts mid-word ("Staff Platform Engin…"). Cut at a word.
   4. A job whose latest file is damaged is listed by its URL path, but its detail heading uses the title, and the "(latest revision)" toggle label then shows revision 1. Use one name, and label the toggle with the revision actually shown.
   5. **The pinned line** (P03.2's round-1 critic). At 640 px and below, the tag runs into the message for assistive tech ("LAST ACTIONExtracting…"). Use the separator P03.2 settled (Q9): the visible tag keeps its words, and a visually hidden ": " separates it.
   6. **The runner is down** (P05's V13). The Jobs page is silent while the runner is down. Use the notice P05 added: show and announce "Can't reach the runner. Is it still running?" once, and clear it on the next good refresh.
   7. **A repeated refusal** (P05's round-3 critic, the shared pattern). A repeated identical refusal first announces the tag alone ("Refused"). Announce the whole line each time.
2. **The server nits** (P04's round-3 reviewer).
   1. A Re-extract whose waiting-state write fails (for example, `extraction-1.json` is a directory) returns a generic 500. Refuse plainly instead.
   2. A job directory that can't be read (for example, chmod 000) drops out of the list, and its detail says "No such job". List it as unreadable and name the folder, as T6 does for files.
3. **Shared styles** in `runner.css`.
   1. The secondary button's border (`#detail-retry` and every `.secondary` button) is 1.27:1. Where the border is the button's only visible boundary, it needs 3:1 (WCAG 1.4.11). Use `--muted-foreground`, as G7 does for form controls.
   2. In light theme, `.error` text is #e54b4f on white, 3.85:1 (axe serious). Bring it to at least 4.5:1 in both themes.
   - Check every runner page that uses either rule.
4. **The Status page** (P03.2's round-2 and round-3 critics).
   1. "Check the model" drops focus to the page body while the check runs, and its result is never announced. Keep focus on the button, mark it `aria-disabled` while busy, and announce the result once.
   2. The eve line shows the eve client's raw error text. Phrase it for a person.
   3. The two 1280 `docs/screenshots/P03.2-status-model-check-failed-*.png` shots include a line from the test setup ("eve is not answering…"). Retake them after these changes.
