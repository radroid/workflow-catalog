## Goal
Deliver the source modes P03 deferred, so every F4 category can be provided the way spec §4 names:
- a dropped PDF or DOCX;
- an exported data archive;
- a public page by URL;
- repositories through a read-only GitHub token.

## Deliverables
- **PDF and DOCX upload.**
  - Text is extracted locally in the runner. It goes nowhere except the extraction model call.
  - Libraries must be maintained, with no native build step, no install scripts and no network access. Pin exact versions, and report the choice and the reason.
  - Caps: file size (10 MB), extracted text (P03's per-source cap), and a time budget.
  - An encrypted or malformed file gives a plain error, never a crash.
  - The raw file lands under `sources/<category>/` with P03's file-name confinement.
- **Exported archives** (LinkedIn and similar, "uploaded as a file" per §4).
  - A ZIP is read in memory, never unpacked to disk.
  - CSV, TXT, MD and JSON entries become the source text.
  - Caps: entry count, per-entry size, total uncompressed size and compression ratio (zip-bomb guard).
  - Entry paths are never used as file paths.
- **URL import** (portfolio or site, and public profile pages the person owns).
  - Fetch through P04's `safe-fetch`: https only; no loopback, private, link-local or metadata addresses, checked after DNS resolution and on every redirect; a redirect limit, a size cap and a timeout; `text/html` or `text/plain` only.
  - Extract the text with P04's `readable-text`.
  - The fetched text is stored as the source file and extracted like any other source.
- **GitHub token** (the repositories category), read-only.
  - Use `gh auth token` when the gh CLI is signed in. Otherwise, a fine-grained PAT is pasted once and stored in the OS keychain through `runner/lib/secret-store.ts` (service `workflow-catalog-runner`, name `github-token`).
  - The token never appears in the workspace, the journal, logs, the UI or any response.
  - The runner reads the person's own repositories into one source text: name, description, languages, topics, and the README up to a cap.
  - `npm run setup -- --forget` lists and removes the keychain entry.
- **Local UI.**
  - The Onboarding page offers these modes per category, alongside paste and TXT/MD upload.
  - It keeps the focus, announcement and contrast rules from P03's revision.

## Acceptance
- **Documents and archives:**
  - Fictional fixture files (Ada Quill) in PDF, DOCX and ZIP extract to the expected text.
  - A malformed file, an encrypted PDF, an oversized file and a zip bomb each give their plain error.
  - Nothing is written outside `sources/<category>/`.
- **URL import:** refused targets are `http:`, `file:` and `javascript:` URLs, loopback, RFC 1918, link-local and `169.254.169.254`. This includes a public host that redirects to one or resolves to one. Tests use an injected resolver and a local fake server, never the real network.
- **GitHub:**
  - Against a fake GitHub API, the source text lists the fixture repositories.
  - The token appears in no file, journal entry, log line or response. Assert by grep over the temp workspace and captured output.
  - `forget` removes the entry.
- **Hostile content:** a document, archive or page containing instructions yields claims only, with no tool other than `extract_claims` called.
- `pnpm typecheck && pnpm test && pnpm -r lint && pnpm check:fixtures` is green, and `npm run eval` in `runner/` is green.

## Out of scope
- Login-gated fetches, scraping, and OAuth.
- Formats beyond those named.
- Job capture (P04).
